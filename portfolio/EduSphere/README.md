# EduSphere

EduSphere is a full-stack Learning Management System (LMS) with a React + Vite client and an Express + MongoDB server.

## Requirements
- Node.js (v18+ recommended)
- npm
- MongoDB (local or hosted) running and accessible

## Project layout
- C:\Users\moham\portfolio\EduSphere\client — React front-end (Vite)
- C:\Users\moham\portfolio\EduSphere\server — Express API server

## Environment
Create a `.env` file in the server directory (server/.env). Example:

MONGO_URI=mongodb://127.0.0.1:27017/edusphere
CLIENT_URL=http://localhost:5173
JWT_SECRET=your_jwt_secret_here
PORT=5000
NODE_ENV=development

Notes:
- MONGO_URI must point to a running MongoDB instance.
- CLIENT_URL should match the address where the client is served.

## Troubleshooting
- "Cannot connect to MongoDB" — ensure MongoDB is running and MONGO_URI is correct.
- Port conflicts — change PORT in server/.env or the Vite port in client config.
